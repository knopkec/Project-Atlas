# 02: Hospital and Department

**What to build:** the ability to create and list hospitals, and to create and list departments under a hospital. This establishes the Hospital → Department hierarchy with Department as the integration unit.

**Blocked by:** 01 (App and database foundation)

**Status:** ready-for-agent

- [ ] A hospital can be created with a name and read back by id
- [ ] Hospitals can be listed
- [ ] A department can be created under a hospital and read back by id
- [ ] A hospital's departments can be listed
- [ ] Creating a department under a non-existent hospital fails cleanly
